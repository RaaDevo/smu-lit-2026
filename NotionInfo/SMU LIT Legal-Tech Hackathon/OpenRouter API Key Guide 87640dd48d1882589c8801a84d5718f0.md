# OpenRouter API Key Guide

# Table of Contents

## Overview

Setting up your AI agent coding tool with OpenRouter is straightforward. This guide walks you through it to simplify the process. 

## API key

Each team is provided with a team API key. This key is unique to your team and should not be shared outside your team.

## 1) Choose your AI agent coding tool

Pick a tool to use with OpenRouter. Options include:

- OpenCode
- VSCode extensions
    - Kilo Code
    - Cline

## 2) Connect your OpenRouter API key

Once you’ve installed your tool, connect your OpenRouter API key in that tool’s settings.

## Example: OpenCode setup

1. Click the `Settings` button

![image.png](OpenRouter%20API%20Key%20Guide/image.png)

1. Click the models button and click the `+ Connect` for OpenRouter. Input your OpenRouter key and you are connected!

![image.png](OpenRouter%20API%20Key%20Guide/image%201.png)

1. Create a session. Navigate to the home page and click **`Add project` . Create your project**
    
    > Note: For OpenCode, you need to create a project first before you start a session. The process of creating a project is just simply creating a folder.
    > 

![image.png](OpenRouter%20API%20Key%20Guide/image%202.png)

1. Once you have entered a session, click the button as shown below to toggle your model

![image.png](OpenRouter%20API%20Key%20Guide/image%203.png)
